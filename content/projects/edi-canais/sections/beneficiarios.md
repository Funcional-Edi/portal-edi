# Gateway de Beneficiários

**Conteúdo pendente.** Esta seção documentará a integração para consulta e
gestão de beneficiários (dependentes, saldo, histórico de uso do benefício).
O conteúdo detalhado ainda precisa ser consolidado nesta documentação, com
descrição, regras de negócio e exemplos reais das operações GraphQL
correspondentes.

Quando o gateway (`stores-uat.funcionalmais.com/graphql`) for conectado e o
schema sincronizado, as operações relacionadas a beneficiários devem ser
adicionadas ao roteiro com `relatedSections: ["beneficiarios"]`.
