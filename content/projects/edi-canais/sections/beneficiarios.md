# Gateway de Beneficiários

**Conteúdo pendente.** No site legado, esta seção documenta a integração
para consulta e gestão de beneficiários (dependentes, saldo, histórico de
uso do benefício). O texto detalhado ainda não foi migrado — falta receber
o print/texto da página original para curar descrição, regras de negócio e
exemplos reais das operações GraphQL correspondentes.

Quando o gateway (`stores-uat.funcionalmais.com/graphql`) for conectado e o
schema sincronizado, as operações relacionadas a beneficiários devem ser
adicionadas ao roteiro com `relatedSections: ["beneficiarios"]`.
