# Gateway de Credenciado

**Conteúdo pendente.** No site legado (`developer.funcionalmais.com`), esta
seção documenta as APIs de autorização de vendas por estabelecimentos
credenciados (PBM e cartão de Benefício Farmácia). O texto detalhado desta
página ainda não foi migrado — falta receber o print/texto da página
original para curar descrição, regras de negócio e exemplos reais das
operações GraphQL correspondentes.

Quando o gateway (`stores-uat.funcionalmais.com/graphql`) for conectado e o
schema sincronizado, as operações relacionadas a credenciamento devem ser
adicionadas ao roteiro com `relatedSections: ["credenciado"]`.
