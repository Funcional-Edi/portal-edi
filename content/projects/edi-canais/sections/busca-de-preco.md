# Busca de Preço

**Conteúdo pendente.** No site legado, esta seção documenta a consulta de
preços de produtos/medicamentos usada no fluxo de venda pelo estabelecimento
credenciado. O texto detalhado ainda não foi migrado — falta receber o
print/texto da página original para curar descrição, regras de negócio e
exemplos reais das operações GraphQL correspondentes.

Quando o gateway (`stores-uat.funcionalmais.com/graphql`) for conectado e o
schema sincronizado, as operações relacionadas a busca de preço devem ser
adicionadas ao roteiro com `relatedSections: ["busca-de-preco"]`.
