# Diretrizes de Segurança e Consumo da API

- Obtenha o token antes das chamadas do fluxo e siga o contrato de autenticação.
- Use somente dados de teste liberados para homologação; mascare CPF, telefone, e-mail e outros dados pessoais nas evidências.
- Trate erros e mensagens retornados pela API sem ocultar a causa operacional.

> **ATENÇÃO MÁXIMA:** Não registre nem compartilhe tokens, senhas ou dados pessoais reais em exemplos, capturas de tela ou logs de homologação.

> **COMENTÁRIO:** A fonte de refinamento não detalha política de renovação do token, limites de chamadas ou códigos de erro; esses pontos dependem do contrato da autenticação/API.
