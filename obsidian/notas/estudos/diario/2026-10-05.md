# 2026-10-05

## O que fiz

Instalei o Node 24.21.0 com `nvm install 24` e ativei com `nvm use 24.21.0`.

## O que aprendi

`nvm install 24` escolhe a versão completa sozinho. Aqui ficou `24.21.0`.
O `nvm use` só aceita um número que apareça em `nvm list`.

## O que travou

`nvm use 24.11.0` respondeu `activation error: Version not installed`.
Esse número era um exemplo, não a versão instalada. O comando certo foi `nvm use 24.21.0`.
