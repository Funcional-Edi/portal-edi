## O que aprendi

- **Junction no Windows** — `obsidian/docs` não é cópia, é um atalho de pasta. Editar em
  um lugar reflete no outro porque é o **mesmo** arquivo no disco. Por isso está no
  `.gitignore`: o conteúdo real já é versionado em `docs/`
- **Geração a partir de fonte única** — as notas de `produtos/` saem de `manual.json`.
  Editar a nota gerada é inútil (o sync sobrescreve); a correção vai na origem
- **`watch` com debounce** — salvar um arquivo dispara vários eventos do sistema. O
  script espera 400 ms antes de sincronizar para não rodar 5 vezes seguidas
- **PowerShell não aceita `&&`** nesta versão. Usar `;` — descoberto na prática, ao ver
  o erro `O token '&&' não é um separador de instruções válido`
- **`npm run ci` para na primeira falha**, então a etapa que quebrou já indica o tipo do
  problema

## O que travou
